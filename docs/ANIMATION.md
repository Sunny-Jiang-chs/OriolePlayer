# 桌面与 Android 动态页面预览

共享协议使用 CGSceneKit 0.2.1 / CG Scene Package 1.2.0。权威字段说明在 [schema/README.md](../schema/README.md)。旧 1.0 / 1.1 静态包继续按原路径播放。

## 本地启动

```powershell
cd D:\MyP\MediaSuite\CGSceneStudio
npm run build:cubism
npm run demo:animation
npm start
```

打开 `http://127.0.0.1:8768/?package=./datasets/animation-demo/package.json`。若已有服务占用该端口，使用 `node server.mjs --port 8772` 并修改 URL 端口。Cubism 构建默认使用 D:\tools\CubismSdkForWeb-5-r.5 和用户目录下的 Bun；可传 SDK 目录参数并用 BUN_EXE 指定 Bun。常规播放使用已生成的本地运行时，无须再次构建或访问网络。

Wanko 是 SDK 示例，用于验证循环、单次播放、表情、参数、跨页延续、清屏与缺失占位；不含游戏提取图片。生成的 datasets/animation-demo 不进入源码提交。构建器保留 Core / Framework / SDK 许可文件；Core 和模型不适用项目自有源码的许可。

示例还有“视频与跨页延续”场景，使用 FFmpeg 生成的三秒测试图案；生成器默认使用 D:\tools\ffmpeg\ffmpeg-9.0.1-essentials_build\bin\ffmpeg.exe，可用 FFMPEG_EXE 指定本机路径。完整演示共两个场景、十页。

必要的功能检查可打开 `/scripts/animation-smoke.html`。它使用 SDK / 合成素材检查循环越界、实际参数变化、暂停、跨页实例、清屏、视频起点和目录导入，不读取原游戏素材。日常视觉核对直接使用播放器，无须重复运行检查。

## 预览行为

- 页面继续代表一段对白，不是动画帧。翻页按 next / choices，声音使用现有页级声音事件。
- 静态图、静音视频、Live2D 可以叠放；全屏按比例适配，不拉伸模型。
- 同一实例跨明确连接延续；手动跳页或返回历史按目标页快照重建。显示状态是完整快照，空图层会真正清屏。
- “暂停动画 / 继续动画”控制视觉播放，“重播本页动画”恢复该页视觉起点，均不重触发语音/BGM。参数/部件在动作和物理之后覆盖。
- 页面信息的“显示图层”展示类型、载入状态、实例及错误。任一图层失败会明确占位。
- 模型资源从包内加载；model3 内依赖必须登记，目录导入也能解析纹理/动作，不依赖原游戏绝对路径。
- 浏览器视频格式支持取决于编码，MP4 建议 H.264、WebM 建议 VP8/VP9。视频的内嵌音轨静音，需将音轨作为 audio 资源显式绑定。

## 整理器与 Android 0.3.0

整理器接受 1.2 图层快照，按可见且可用的 `event-cg` 图层统计每页 CG，支持同页多个图层、明确清屏和未知演出。动态页单独计数；连续缩略图墙按首个 CG 页的完整图层在本机生成预览，Live2D 加载页面动作、表情、参数与部件后取静态帧，视频静音取帧，不把模型 JSON 或单张纹理当成 CG 缩略图。预览失败显示原因并可重试，缩略图不参与自动分类。整场景重导出包含被引用模型的全部 `dependencies`，保留动作、表情、参数、部件、声音及连接快照。

Android 0.3.0 的目录和 ZIP 导入接受 1.2，并检查模型依赖。原生导入器流式扫描清单，只保存作品信息、场景页数与资源路径，避免在 Java 堆中重复展开整份对白和来源数据；网页播放层仍会载入完整标准包。

手机使用与桌面相同的本地 Cubism / 视频播放层。触控设备的模型更新目标为 30 帧，画布上限为 2048、像素比上限为 1.5；仅在纹理超过 GPU 的最大尺寸时等比缩小。暂停和进入后台停止模型绘制，返回前台保留手动暂停状态。原始媒体和包结构不变。重播动画不重触发配音或 BGM。

大作品建议先在整理器选出要核对的完整场景，再转移整个输出目录或打成 ZIP。手机的内存、WebView 版本和 GPU 会影响可载入的模型大小与流畅度；本轮只完成结构检查及 APK 构建，实际设备表现需本地验收。

## 当前边界

动态预览需要浏览器 / Android WebView 支持 WebGL；视频编码支持依设备而定。资源失败仍按图层给出占位信息。

Live2D 当前支持一个主动作、一个表情、参数与部件覆盖、模型物理和 pose。不会执行游戏脚本，不能保证还原来源特有多轨混合、variable motion、摄像机或时间轴效果。非零 startTime 定位动作，不补算之前的物理历史。

`hspy/extraction.json` 是来源证据，不是播放入口。现有 `hspy-playable/package.json` 已关联媒体与动作并清理文本格式码，可用于整理与播放；仍不代表完整原游戏复刻。来源模型的 `mosaic` 网格专用后处理尚未实现，部分动态画面可能出现有色辅助网格；此限制同样适用于手机。
