# 黄鹂播放器

> 共同工作区：[MediaSuite](../README.md) · 共同开发与前端规范：[AGENTS.md](../AGENTS.md)。

使用日光系列图标：金鸟、日轮与暖象牙背景，和场景工坊「拾景」配套。图标母版及平台适配说明见 [品牌素材](assets/branding/README.md)。

面向 CG 创作者与视觉小说作者的本地预览工具。把每页的画面、对白、配音、背景音乐和选项组织为 **CGScene Package**，即可在桌面浏览器或 Android 手机上阅读与核对。

播放器与导出工具独立维护：本仓库提供播放器、固定版本的共享格式模块、标准包打包工具和独立创作的示例。解析器与场景整理器位于相邻的 `CGSceneParsers`，不随播放器发布。公共格式和纯数据代码由 `CGSceneKit` 维护；本仓库带有可独立运行的版本快照，无需同时安装另外两个项目。

## 下载与开始使用

在 [Releases](https://github.com/Sunny-Jiang-chs/huangli-player/releases) 页面下载。2026-10-15 核对 GitHub 官方发行记录，当前公开版本为 [v0.2.3](https://github.com/Sunny-Jiang-chs/huangli-player/releases/tag/v0.2.3)，与下方当前源码能力分开说明：

| 文件 | 使用方式 |
| --- | --- |
| `HuangliPlayer-0.2.3-release.apk` | 安装到 Android 手机，导入该版本支持的标准数据包 |
| `HuangliPlayer-0.2.3-web.zip` | 解压后在电脑启动本地网页播放器 |

两种版本均内置小型创作者示例。自己的作品作为独立数据包导入，不需要重新编译播放器。本文后续的 1.2 动态图层和作品空间管理说明对应较新的源码，不能视为公开 v0.2.3 已包含；后续发行以 Releases 的实际记录为准。

### Android

支持 Android 8.0（API 26）及以上，当前目标版本为 Android 16（API 36）。

1. 安装 APK 并打开 **黄鹂播放器**。
2. 点顶部 **目录**，选择 **浏览目录（含隐藏）**、**系统目录选择器** 或 **导入 ZIP 数据包**。
3. ZIP 根目录或所选文件夹中应有 `package.json` 以及它引用的媒体文件。
4. 选择场景即可播放，声音默认开启；点击声音按钮可静音。可旋转手机或进入沉浸全屏阅读。

数据包保存在手机本地，预览无需电脑运行服务。ZIP 导入会保存一份解压副本；选择文件夹则直接访问原目录。内置目录浏览器显示以点开头的隐藏目录，记住上次浏览位置，并在识别到作品时显示场景与页数；首次使用时申请文件访问权限。系统目录选择器仍可单独授权一个目录。详细操作与构建方法见 [Android 说明](docs/ANDROID.md)。

当前源码版本为 **0.3.1**，Android 新增作品位置与空间管理：查看导入副本的占用、移入回收站、恢复或确认清理；外部目录可查看位置及移除关联。保留 0.3.0 的 1.2 静态图层、视频与 Live2D 播放，以及完整模型依赖检查、流式导入清单和触控动画控制。公开下载版本以 Releases 页面为准；本地新构建位于 `dist/latest/`。

### 桌面浏览器

安装 Node.js 后，Windows 用户双击 `Start.cmd`，即可启动本地服务并打开浏览器。默认端口为 8768；自动启动脚本遇到端口占用时会寻找后续可用端口，重复启动可复用当前项目的服务。

也可以在解压目录或仓库根目录执行，无需安装 npm 依赖：

```sh
npm start
# 或
node server.mjs
```

打开 `http://127.0.0.1:8768/`，用文件夹按钮选择完整数据包目录。目录访问功能取决于浏览器，建议使用较新的 Chrome 或 Edge。也可将自己的包放到 `datasets/my-project/`，通过下列地址打开：

```text
http://127.0.0.1:8768/?package=./datasets/my-project/package.json
```

## 阅读与预览

- **逐页阅读**：点击画面、方向键或滚轮切页；页码和进度条用于直接定位。
- **长按快进**：按住画面或对白区约 0.45 秒后连续翻页，松开即停；遇到选项或段落终点会停止。快进跳过短配音与单次音效，BGM 按页面切换；松开后播放当前页配音，原先开启的自动阅读会继续。
- **自动推进**：自动模式下点击画面会继续自动计时；手动定位进度会暂停自动。非循环主配音播放时，自动阅读等待其结束。
- **沉浸全屏**：Android 进入全屏时切换横屏，退出后恢复原方向策略。隐藏工具栏和底部进度条，画面按原比例最大化，对白叠在画面底部。右上角按钮、桌面 Esc 或 Android 返回键退出。
- **对白框透明度**：工具栏“阅读设置”提供 0%（不透明）至 100%（全透明）的滑块，只调整底色和边框，文字保持清晰，并在本机记住设置。
- **声音控制**：支持逐页配音、音效与跨页 BGM，分别调整 BGM 和其他音频音量，并在本机记住设置。
- **作品管理（Android）**：在“目录 → 作品管理（位置与空间）”查看位置与导入占用。ZIP 副本可移入回收站、恢复或彻底清理；外部目录只移除记录，保留原文件。
- **场景查找**：列表左侧按需载入首张事件 CG 缩略图；旧包缺少角色标记时，首张可用画面会标为“CG 待核”。支持搜索、分类、事件 CG 筛选和当前场景定位；手机竖屏上方预览、下方场景列表独立滚动，横屏使用抽屉，桌面保留侧栏。
- **明确的占位**：数据包标记为特殊演出或未解析的页面显示对应提示，避免把上一页画面误当成当前画面。

声音默认开启。桌面浏览器若限制自动播放，会在首次点击或按键时开始播放。切到 Android 后台会暂停声音和自动推进；返回后续播原有声音，保留手动静音选择，自动翻页需手动继续。

## 数据格式与解析器边界

电脑端和 Android 0.3.0 支持 **CGScene Package 1.0 / 1.1 / 1.2**；1.2 增加静态图、视频、Live2D 图层与跨页动画实例。使用方式与本地演示见 [动态页面预览](docs/ANIMATION.md)，字段约定见 [格式说明](schema/README.md)。公开发布版能力以对应版本说明为准。

入口是 `package.json`，媒体 URI 相对于该文件；复制整个目录即可迁移。模型的 dependencies 也必须一起复制，标准包打包脚本已包含这些文件。

```text
my-scene-package/
  package.json
  media/
    opening.webp
    voice-001.ogg
    theme.ogg
```

每页的 `text` 保存说话人与对白，`visual` 引用画面资源，`audioEvents` 定义有序声音动作。1.0 默认顺序阅读；1.1 可通过 `entryPageId`、`next` 和 `choices` 表达明确的段落连接与分支。直接跳页的声音基线也由标准字段提供。

完整字段定义见 [格式说明](schema/README.md)，可运行的创作模板见 [示例数据包](datasets/example/package.json)。新作品可直接使用标准图像与音频编写数据包。需要接入其他引擎时，由独立解析器把资源及脚本引用转换成同一结构；播放器不需要理解原始引擎文件。

当前重点是静态 CG 与按页视觉小说预览。任意游戏脚本、游戏变量、复杂互动状态机、实时立绘合成及精确演出时间轴不属于现有格式的完整还原范围。解析器应明确标记缺失与未确认内容；播放器只能呈现数据包实际提供的信息。

## 打包自己的作品

`scripts/package-dataset.py` 将已经符合标准的数据包打成可导入的 ZIP，它不负责解析游戏。需要 Python 3.10 或以上：

```sh
python scripts/package-dataset.py --input datasets/my-project --output dist/packages/my-project.cgscene.zip
```

默认保留原媒体文件。可选 `--audio-format ogg --ffmpeg <ffmpeg可执行文件>` 生成更小的有损音频副本，源数据包保持不变；音质与循环衔接需由作者确认。

## 项目结构与开发

| 路径 | 内容 |
| --- | --- |
| `player/` | 通用网页播放器、数据加载器和图像解码插件 |
| `player/vendor/cgscene/` | CGSceneKit 的固定版本模块；公共数据模型与工具，不依赖导出器 |
| `android/` | Android WebView 容器、含隐藏目录的本地浏览器、系统文件选择和本地包管理 |
| `schema/` | CGSceneKit 同步来的数据格式说明与 JSON Schema |
| `shared-lock.json` | 共享模块版本与文件摘要，用于检查同步结果 |
| `datasets/example/` | 独立创作的示例文本、画面和声音 |
| `scripts/package-dataset.py` | 标准数据包 ZIP 打包工具 |
| `docs/ANDROID.md` | 手机端安装、构建和使用说明 |

修改网页后可直接重新加载桌面预览；Android 版需重新构建。Windows 双击 `Build-Android.cmd`，或使用 `build-android.ps1`。`Start-Android.cmd` 用于已配置 Android SDK 与 AVD 的开发电脑：先增量构建当前 debug 预览包，再启动模拟器、安装并打开播放器；若确认包已是最新，可传 `-SkipBuild` 跳过构建。

本地安装入口统一在 **`dist/latest/`**。旧包自动移入 `dist/archive/<版本>/<构建ID>/`，不会被新构建覆盖；每份包附有 Git 提交号、构建时间、未提交状态和 SHA256。源码变更后只构建 Debug 时，旧 Release 会移出当前入口，避免混用。构建需 Python 3.10+ 与 Git；详见 [版本与构建管理](docs/VERSIONS.md)。

第三方组件及其许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本次 APK 沿用本地开发签名与应用标识，方便已有安装覆盖升级；它不是应用商店发布签名配置。

## 在桌面筛选与重新导出

场景整理器名为「拾景」，已归入独立的导出工具 `CGSceneParsers`，从该项目双击 `Start.cmd`，默认打开 `http://127.0.0.1:8780/organizer/index.html`。本项目的 `Start-Organizer.cmd` 仅保留为本地开发转发入口，不进入播放器发行包。

当 `CGSceneParsers` 放在相邻目录时，本地播放器服务可挂载整理器网页，显示顶部“拾景”入口，并传递当前 URL 加载的数据包。它读取的是导出工具的源文件，播放器目录不保留第二份整理器。目录选择器加载的包需在整理器重新选择。独立播放器安装不显示该入口。

整理器按整场景选择，保留 CG 前后对白与声音，并将结果另存为标准包；完整说明见 [整理器文档](../CGSceneParsers/organizer/README.md)。共享边界和修改方式见 [开发架构](docs/ARCHITECTURE.md)。整理功能只在桌面提供，Android 继续播放标准包。
